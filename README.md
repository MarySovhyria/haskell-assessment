**Karma Game**

**Overview**
This Haskell program implements Karma, a dynamic card game where players aim to be the first to empty their hand, face-up, and face-down cards. The implementation follows a structured, functional approach, modeling the game state and rules using pure functions and the State monad for stateful operations.

The code provides a complete simulation engine for Karma, including core game logic, player strategies, and tournament functionality. It supports both single-game play and repeated simulations to compare AI strategies.

**To Run The Code**
ghci Karma.hs
